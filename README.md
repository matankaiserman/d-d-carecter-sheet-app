# D&D 2024 Character Companion

Offline mobile character sheet (PWA). Open https://matankaiserman.github.io/d-d-carecter-sheet-app/ and add it to your home screen.

## Credits
Spell data: System Reference Document 5.2 by Wizards of the Coast LLC, licensed under CC-BY-4.0 (https://creativecommons.org/licenses/by/4.0/). JSON via 5e-bits/5e-database (MIT).
Class features, subclasses, Eldritch Invocations, Metamagic and feats (rules.json): System Reference Document 5.2.1 by Wizards of the Coast LLC, CC-BY-4.0, converted from downfallx/dnd-5e-srd-markdown. Rebuild with tools/make_rules.py.

PDF reading: Mozilla PDF.js (Apache-2.0), bundled as pdf.min.mjs / pdf.worker.min.mjs. roll20.js parses the Roll20 D&D 2024 sheet export.
